# Data Cleaning & Visualization Project

## Overview
This project focuses on cleaning raw sales data and generating meaningful insights using visualization techniques.

## Features
- Handling missing values
- Removing duplicates
- Outlier detection using IQR
- Data visualization using Matplotlib & Seaborn

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Steps
1. Load dataset
2. Clean data
3. Remove outliers
4. Visualize trends

## Outputs
- Cleaned dataset
- Sales trend graph
- Correlation heatmap

## How to Run
pip install -r requirements.txt  
python scripts/main.py
